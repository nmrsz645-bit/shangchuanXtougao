API 投稿 2.0 桌面版

1. 双击 API_Posting_2.exe 进入管理界面。
2. 第一次使用先在“授权”页填写配置并导入授权。
3. 在“账户项目”页检测账户项目。
4. 在“投稿方案”页选择或新建方案。
5. 在“运行状态”页点击“启动投稿”。
6. 需要开机自动启动时，双击“开启开机自启.bat”。
7. 需要关闭开机自启时，双击“关闭开机自启.bat”。

注意：
- 本程序不需要另外安装 Python。
- 请放在可写目录运行，例如 D:\自动化 或 E:\自动化。
- 不建议放在 C:\Program Files。
- 发布包默认不包含授权 token、数据库和日志。
